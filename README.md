# Akali Tatto
Sitio web desarrollado para Akali Tattoo, un estudio de tatuajes profesional. El proyecto forma parte del curso de Desarrollo Web en Coderhouse.

---
## 🚀 Tecnologías utilizadas
* **HTML5:** maquetación semántica y accesible.
* **CSS3:** diseño responsivo con CSS Grid (`grid-template-areas`), Flexbox y Media Queries (Mobile-First).
* **Bootstrap 5:** componentes interactivos como Carrusel y Barra de navegación.
* **Google Fonts:** tipografía *Cormorant Garamond*.

---
## 📂 Estructura del proyecto
* `index.html` — Página principal de bienvenida con carrusel destacado.
* `pages/artistas.html` — Presentación del staff de tatuadores y sus especialidades.
* `pages/galeria.html` — Galería de trabajos organizada mediante CSS Grid responsivo.
* `pages/contacto.html` — Formulario de contacto y turnos.
* `pages/blog.html` — Artículos sobre cuidados y estilos de tatuaje.
* `style/style.css` — Hoja de estilos personalizados.
* `img/` — Recursos gráficos y fotografías de los tatuajes.
