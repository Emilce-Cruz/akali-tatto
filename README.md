# Akali Tattoo
Sitio web desarrollado para **Akali Tattoo**, un estudio de tatuajes profesional. Proyecto final correspondiente al curso de Desarrollo Web en Coderhouse.
---
## 🌐 Sitio web desplegado (Netlify)
👉 [Visitar Akali Tattoo](https://akalitatto.netlify.app)
---
## 🚀 Tecnologías utilizadas
* **HTML5:** maquetación semántica, accesible y optimización de SEO on-page (meta tags únicos y jerarquía de encabezados).
* **Sass / SCSS:** arquitectura modular organizada en partials, variables, mixins con parámetros, extend y nesting, compilada a CSS.
* **Bootstrap 5:** componentes responsivos (Barra de navegación y Carrusel) personalizados mediante SCSS.
* **CSS Grid & Flexbox:** maquetación responsiva con diseño adaptativo en mobile, tablet y desktop sin scroll horizontal.
* **Animaciones:** transiciones nativas en CSS/SCSS e integración de animaciones mediante librería externa (AOS / Animate.css).
* **Google Fonts:** tipografía *Cormorant Garamond*.
---
## 📂 Estructura del proyecto
* `index.html` — Página principal con carrusel destacado y presentación del estudio.
* `pages/artistas.html` — Staff de tatuadores y especialidades de cada artista.
* `pages/galeria.html` — Muestra de trabajos organizada mediante CSS Grid responsivo.
* `pages/contacto.html` — Formulario de contacto, turnos y mapa de ubicación.
* `pages/blog.html` — Artículos sobre cuidados y estilos de tatuaje.
* `scss/` — Archivos fuente de Sass organizados en partials (`main.scss`).
* `styles/` — CSS compilado a partir de SCSS.
* `assets/` (o `img/`) — Recursos gráficos, fotografías e íconos.
